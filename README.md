# Sup'RH School Intelligent Chatbot (Botpress Project)

![Sup'RH Chatbot Project Banner](https://github.com/user-attachments/assets/cd7bd4dc-84f2-42ca-9e16-f70811289a05)

## 📌 Overview
This project was developed during the **CodeXperience Hackathon**, organized by **Sup'AI** from **Sup'RH** school. The objective was to create an intelligent chatbot capable of answering Sup'RH student and faculty questions and concerns, while seamlessly integrating with the school's website.

This chatbot was built using **Botpress** and features a **custom hook** (`src/hooks/trackIterations.ts`) designed to track and analyze the iterations of improvements generated by an LLM, facilitating continuous enhancement of the chatbot's responses.

## 📁 Project Structure
The project is organized as a standard Botpress export, with key custom elements typically found in:
- **`src/hooks/trackIterations.ts`**: Custom Botpress hook to monitor and log the performance and changes of LLM-generated responses over time, enabling continuous improvement of the chatbot.
- **`src/flows/`**: Contains the JSON definitions for various conversation flows within the bot.
- **`src/actions/`**: Houses custom TypeScript actions that the bot can execute during conversations.
- **`docs/captures/`** (Assumed, based on original README): Likely contains screenshots for documentation. *(Note: This path was mentioned in the original README but is not standard in Botpress exports directly. Screenshots are usually added to documentation manually.)*

Development and configuration primarily occur within the Botpress Studio cloud interface.

### Integrating with React
Botpress provides React components for a flexible way to build and customize chatbot interfaces.

1.  **Install Packages:**
    ```bash
    npm install @botpress/webchat @botpress/webchat-generator
    ```
2.  **Obtain Client ID:**
    - Open your bot in the Botpress Workspace.
    - Navigate to the "Webchat" tab (or "Integrations" -> "Webchat").
    - Access "Advanced Settings" or look for "Client ID" in the configuration details.
    - Copy your `Client ID`.
    ![Botpress Webchat Tab showing Client ID location](https://github.com/user-attachments/assets/5876b0a1-b46c-4c43-ab74-00ba343994bb) *(Screenshot showing where to find Client ID in Botpress)*

3.  **Add Code to Your React App:**
    ```javascript
    import { Webchat, WebchatProvider, Fab, getClient } from "@botpress/webchat";
    import { buildTheme } from "@botpress/webchat-generator";
    import { useState } from "react";

    const { theme, style } = buildTheme({
      themeName: "prism",    // Or any other theme: "ocean", "bubble", "social" etc.
      themeColor: "#634433", // Customize your bot's color
    });

    // ⚠️ Replace with your actual Client ID from Botpress Studio
    const clientId = "YOUR_BOTPRESS_CLIENT_ID";

    export default function App() {
      const client = getClient({ clientId });
      const [isWebchatOpen, setIsWebchatOpen] = useState(false);

      const toggleWebchat = () => {
        setIsWebchatOpen((prevState) => !prevState);
      };

      return (
        <div style={{ width: "100vw", height: "100vh" }}> {/* Adjust as needed */}
          <style>{style}</style>
          <WebchatProvider
            theme={theme}
            client={client}
          >
            <Fab onClick={toggleWebchat} />
            <div
              style={{
                display: isWebchatOpen ? "block" : "none",
                position: "fixed", // Example styling for overlay
                bottom: "100px",
                right: "20px",
                width: "400px",   // Adjust dimensions
                height: "600px",  // Adjust dimensions
                zIndex: 1000
              }}
            >
              <Webchat />
            </div>
          </WebchatProvider>
        </div>
      );
    }
    ```

### Integrating with Webflow
![Webflow Custom Code Interface](https://github.com/user-attachments/assets/b24c51e9-1b9e-4fac-a74d-14870e61d424) *(Screenshot of Webflow's custom code section)*

1.  **Get Webchat Script:** In your Botpress Admin Dashboard, select your bot, go to "Integrations" -> "Webchat", and copy the pre-configured "Embedded" script.
2.  **Embed in Webflow:**
    - Go to your Webflow site's "Site Settings".
    - Navigate to the "Custom Code" tab.
    - Paste the Webchat script into the "Head Code" or "Footer Code" section (Botpress usually recommends footer/end of body).
    - Save changes and publish your site.

### Integrating with Wix
![Wix Custom Code Interface](https://github.com/user-attachments/assets/00e8ec4c-faf9-4412-9419-9da8d580cc3d) *(Screenshot of Wix's custom code section)*

1.  **Get Webchat Script:** Copy the "Embedded" script from your Botpress Webchat integration settings.
2.  **Add to Wix:**
    - In your Wix dashboard, go to "Settings".
    - Scroll to "Advanced Settings" and click "Custom Code".
    - Click "+ Add Code" (or similar, e.g., "Add Custom Code") in the "Body - End" section.
    - Paste the script. Ensure it's applied to all pages and loads once.
    - Apply changes.
    - *For embedding in an HTML div (alternative):* The original README provided detailed instructions. This method gives more control over placement if the standard body script is not suitable. Refer to Botpress documentation for the most up-to-date version of this specific technique if needed. The key is to use an HTML iframe/element and initialize the bot within it using `window.botpress.init`.

    A helpful video from Botpress (around the 18-minute mark for Wix integration):
    [Watch Video](https://www.youtube.com/watch?v=rG7dguRDFIA)

### Integrating with WordPress
![WordPress WPCode Plugin Interface](https://github.com/user-attachments/assets/dbc90441-11db-48b1-8733-ed34ced42b00) *(Screenshot of a WordPress plugin for adding code snippets)*

    ![WordPress WPCode Plugin Installation](https://github.com/user-attachments/assets/50116927-a9e9-44d4-801d-d189072f2e18) *(Screenshot of WPCode plugin activation)*

3.  **Add to WordPress:**
    - Using a plugin like WPCode: Navigate to "Code Snippets" -> "Header & Footer".
    - Paste the script into the "Body" section.
    ![Adding script in WPCode](https://github.com/user-attachments/assets/d405a4aa-95e8-4fbd-8a89-04e1b3679943) *(Screenshot showing where to paste script in WPCode)*
    - Save changes.
4.  **Test:** Refresh your WordPress site to see the webchat widget.
